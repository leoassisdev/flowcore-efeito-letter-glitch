## Como instalar

1. **Crie src/components/LetterGlitch.tsx** Copie o conteúdo de `src/LetterGlitch.tsx` deste repositório.
2. **Sem deps — canvas puro**
3. **Use na página**

   ```tsx
   <LetterGlitch glitchColors={["#3FB5FF","#0066FF","#E0252E"]} glitchSpeed={50} smooth />
   ```
